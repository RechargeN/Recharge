## 1. Зачем

Один термин — один перевод во всех строках интерфейса. Переводы в ARB
написаны по частям в заходах L4.1–L4.6; столбец «Сейчас в ARB» показывает,
где они разошлись. Глоссарий не меняет ARB сам по себе: правки строк
делаются только после решения ревьюера по каждому термину.

Правила, которые действуют уже сейчас:

- **Recharge** — бренд, не переводится и не склоняется по-английски.
- Названия категорий в R1 не переводятся (G04).
- Пользовательский контент (названия, описания, имена) не переводится.
- Пока термин не утверждён, роли и названия продукта (Creator,
  Professional Page, Quick Plan) остаются в lv/ru по-английски — так
  решено в L4.6, чтобы не закреплять случайный перевод.

## 3. Как проводится review (G06)

1. Владелец назначает по одному ревьюеру-носителю для lv и ru
   (BCK20-OD-02). До назначения статус перевода — «не проверен».
2. Ревьюер получает выгрузку `dart run tool/l10n_export.dart` (CSV: ключ,
   описание, плейсхолдеры, en, lv, ru, экран) и скриншоты
   `tool/l10n_screenshots.dart`. Обе выгрузки пишутся вне репозитория и не
   коммитятся.
3. Сначала утверждается этот глоссарий, затем ревьюер правит строки по
   выгрузке. Правки вносит агент или разработчик отдельным заходом; после
   правок — `flutter gen-l10n`, полный `flutter test`, повторные скриншоты.
4. Результат review фиксируется в §17+ amendment (кто, когда, сколько
   строк исправлено, что осталось) и в строке L4 `LAUNCH_STATUS`.

Отдельно ревьюер проверяет: тексты Find People (18+, согласие, приватность
точного места), тексты о GPS-записи Route, юридические формулировки
отказа от гарантий Rental, длинные строки на 360 dp при шрифте ×2.

Дополнительно: Workspace — Darbvieta / Рабочее пространство.

старое утверждение раздела 1 о запрете перевода категорий для этого пакета не применяется.

Латышская ICU-категория zero включает не только 0: проверять также 10, 11, 20,
21 и 100. Использован образец Unicode CLDR; падеж после предлога проверяется
отдельно, поэтому ветви с pēc/līdz/no не исправлялись общей подстановкой.
Источники: https://www.unicode.org/cldr/charts/43/verify/numbers/lv.html ;
https://valodaskonsultacijas.lv/lv/questions/942 .

страница p0. Подписи Created/Visited обрезаются в обоих языках; замечания
записаны в соответствующие CSV. Полная визуальная проверка 293 изображений
не заявляется. Новые категории после Amend требуют свежих скриншотов.
