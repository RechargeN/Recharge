# Viewer Profile — retired document pointer

Status: **Retired — compatibility pointer, not an active specification**
Version: **1.18**
Date: **2026-10-10**

Accepted [ADR 0021](../../adr/0021-unified-personal-profile.md) removes the
separate Viewer presentation. All personal functions remain in one Creator
profile; this UI name grants no role, verification, capability or public
searchability. Professional Pages remain separate work contexts.

Current owner: [Creator common personal requirements](CREATOR_PROFILE_FUNCTIONAL_SPEC.md#common-personal).
Related owners: [Creator personal rules](CREATOR_PROFILE_FUNCTIONAL_SPEC.md#common-personal)
and [public baseline](PUBLIC_CREATOR_PROFILE_FUNCTIONAL_SPEC.md#baseline-context-projection).
Use the [section and VP ID migration map](VIEWER_PROFILE_RETIREMENT_MAP.md)
for exact replacement anchors. Destination full-release requirements remain
Draft; this pointer does not approve their implementation.

Original source, retained byte-for-byte:
[archived Viewer Profile](../../archive/viewer-profile/2026-10-10/specs/docs/product/identity/VIEWER_PROFILE_FUNCTIONAL_SPEC.md.txt).
[Archive manifest](../../archive/viewer-profile/2026-10-10/MANIFEST.md)
and [selective restoration instructions](../../archive/viewer-profile/2026-10-10/RESTORE.md).

This path preserves old bookmarks. It defines no separate Viewer screen,
independent personal-policy owner or public projection. Historic section
bookmarks resolve through the migration map rather than new duplicate rules.
Retirement does not close the outstanding [stage 06 regression gates](../../verification/pvr-01/06-regression.md).
