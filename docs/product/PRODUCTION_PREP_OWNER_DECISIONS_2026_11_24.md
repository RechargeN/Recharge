## Как пользоваться

Каждая строка — одно решение. Рекомендация — вариант агента с причиной. Владелец пишет в колонку «Решение» «да», «нет» или свой вариант. Решение не разрешает операций в облаке: каждая операция production (P-xx в O1) разрешается отдельно.

Ни одно решение ниже не открывает production само по себе. Повтор O1 может дать GO только на создание production-проекта.

## 2. Политики удаления PB-01…PB-18 (Privacy L1)

Сейчас каждая открытая PB даёт честный итог `partially_completed`: данные блокируются, но не удаляются. Решения ниже — продуктовые; юридическую часть подтверждает D-07/D-08.

| ID | Вопрос | Рекомендация | Решение |
|---|---|---|---|
| PB-01 | Identity при удалении: удалить аккаунт или tombstone; судьба согласий | Tombstone без персональных полей (псевдонимный ID, дата удаления, факт согласий без содержания) на срок хранения fence; затем удаление | |
| PB-02 | Опубликованный контент частного автора | Снять с публикации и удалить; брони других людей на Event — см. PB-08 | |
| PB-03 | Page с единственным владельцем | Page снимается с публикации и удаляется вместе с владельцем; при других участниках — передать старшему участнику | |
| PB-04 | Опубликованный отзыв | Анонимизировать автора («Удалённый пользователь»), текст оставить (в R1 отзывов нет — решение на будущее) | |
| PB-05 | Сроки receipts/idempotency/audit не-Booking семей | Receipts и idempotency — 30 дней; audit — 1 год, без персональных полей сверх ID | |
| PB-06 | Legal hold: основание, кто ставит, пересмотр | Ставит только владелец (оператор OB-01) с письменным основанием; пересмотр каждые 90 дней; снятие с записью | |
| PB-07 | Начавшееся занятие | Бронь завершается как обычно; после окончания удаляется по общему сроку | |
| PB-08 | Организатор Event с чужими бронями | Event отменяется, участники получают уведомление об отмене; затем удаление организатора | |
| PB-09 | Жалобы и санкции | Хранить 2 года (Art. 17(3)(e)), личность жалующегося не раскрывать | |
| PB-10 | Admin cases и audit чтения | 1 год, затем удаление | |
| PB-11 | Решения модерации, доверие к автору | 2 года, затем удаление | |
| PB-12 | Общие Scenario/Quick Plan | Доля удаляемого убирается; общий план остаётся у других участников без его данных | |
| PB-13 | Сырой GPS/GPX и ревизии Route | Удалить вместе с аккаунтом; опубликованный Route — по PB-02 | |
| PB-14 | Сроки Media (orphan, quarantine, receipts) | Orphan — 7 дней, quarantine — 30 дней, receipts — 30 дней | |
| PB-15 | Backup и восстановление | Журнал удалений вне БД (D-04); после любого восстановления удаления повторяются по журналу (на staging проверено 2026-11-20) | |
| PB-16 | Срок хранения erasure fence | Равен сроку самого долгого backup (14 дней по D-04) плюс 30 дней | |
| PB-17 | Проверка субъекта и step-up при подаче DSR | Субъект = пользователь текущей Session (как сейчас) + повторный вход Google не старше 10 мин для erasure | |
| PB-18 | Удаление черновика Content и привязок импорта | Добавить команду удаления черновика в Content (задача кода, до когорты) | |

## 3. OD-11 и смежные решения

| ID | Вопрос | Рекомендация | Решение |
|---|---|---|---|
| OD-11 | Минимальный возраст | 16+ с самоподтверждением при входе до заключения юриста (D-08); в Латвии возраст цифрового согласия 13, но бронирования и публикации контента проще ограничить 16+. Find People остаётся выключен | |

| PRIV-CLIENT | Клиент Privacy в приложении | Добавить экран «Скачать мои данные / Удалить аккаунт» до когорты (сервер готов с 2026-11-20) | |
