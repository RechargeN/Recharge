## Сделано

- **Inbox — логический источник.** Push — подсказка после записи inbox (`afterInboxCreated`); нет записи inbox — нет push.
- **Consent/preferences.** Ревизия политики 2 добавляет канал `push`; в закреплённой категории (`booking.changes`) переключается только push, inbox остаётся всегда. Контракт `updatePreferences` разрешает для неё только `{push}` (`lockedChannels`).
- **Token lifecycle.** Токены только на сервере (`notificationPushRegistrations`, отпечаток SHA-256 в логах), один токен — один активный пользователь, регистрация живёт пока жива Session, неактивные 270 дней отзываются; отдельный callable `pushDeviceCommandV1` (installation берётся из Session).
- **Suppression / idempotency / retry.** Лимит 20 в сутки, TTL 24 ч, приоритет normal, общий текст на заблокированном экране; одна попытка на уведомление (`create()`), повторы 30 с × 2^n до 5 попыток, затем dead-letter; невалидный токен — немедленный отзыв.
- **Reconciliation.** `reconcilePushV1` каждые 15 минут (Cloud Scheduler, без публичного invoker) — повторы и устаревшие регистрации, только пока включён kill-switch.
- **Dev-runtime** `dev_notifications_entry.ts` (codebase `n3c-notifications`, не в `index.ts`): протокол callable поверх onRequest, Firebase ID token, Session, allowlist uid владельца, kill-switch, max 1 экземпляр; owner self-test `sendSelfTestNotificationV1` подаёт один синтетический эффект Booking через обычный consumer.
- **Упаковка:** `package-n3c-notifications-runtime.mjs` (замыкание без index, Booking-команд, stand, тестов и реестров контрактов) + predeploy-проверка записи владельца (без автоудаления).
- **Terraform** `n3c_push.tf`: `runtime-notifications` (manifest dev `deployed: true`) — Firestore create/read/update **без delete** на default database, `cloudmessaging.messages.create`, чтение пользователя Firebase; `check-n3c-plan.mjs`. FCM API уже был включён (учтённый побочный эффект провайдера).
- **Mobile:** `firebase_messaging` 16.7.0; только dev debug с `N3C_DEV_PUSH=true`: регистрация токена после входа/восстановления и при ротации, отзыв перед выходом, нет согласия (Android 13+) — нет токена на сервере; нажатие на push открывает inbox, в foreground — SnackBar; inbox из dev-облака; на странице уведомлений — настройки каналов и «Тестовое уведомление»; l10n en/lv/ru.
