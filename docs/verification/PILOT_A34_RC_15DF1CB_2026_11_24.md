### Причина Fail (найдено, исправлено частично)

1. Сервер (ADR 0023) выдаёт `content.create`, `content.submit`, `content.publish`; Create проверяет права по типам (`submit.session`, `create.route`). PR #32 переводит их на границе — тест 4/4.
2. С правкой из PR #32 на A34 отказ остался: Create берёт права из снимка Identity (`activeIdentityAccessProvider`); если снимок не загружен или пользователь не совпадает, остаются только подсказки `create.*`. Нужна отладка состояния снимка на устройстве — следующий шаг.

Сервер публикации (Session/Class/Route) по пилоту 2026-11-21 работает (пробы, Emulator); с телефона до него не доходит.
