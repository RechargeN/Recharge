# RUN-03. Сверка и ремонт (dev, staging)

Статус: **Draft, 2026-11-24.** Консоль Operations (inspect, replay, reconcile, containment) работает только в Emulator: решение владельца 2026-11-24 — в облако не раньше production (OB-01, решение №18 от 2026-11-21). Поэтому в облаке ремонт идёт только через плановые задачи сверки и повторную выкладку. Локальная процедура консоли — `operations-recovery.md`.

## Что сверяется само (плановые задачи в облаке)

| Задача | Семейство | Что делает |
|---|---|---|
| `retryEventBookingProjectionDeliveries` | TF-01 | повторяет доставку проекции брони, исчерпанные — в `deadLetter` |
| `releaseMissedReconfirmations` | TF-02 | обрабатывает пропущенные сроки подтверждения |
| `reconcilePushV1` | TF-03 | повторяет отложенные push, отзывает недействительные токены |
| `runPrivacyRequestsV1` | Privacy | исполняет и сверяет заявки (RUN-04) |

Проверено: 2026-11-23 push `retry_scheduled` повторён плановой сверкой; `registration-token-not-registered` → устройство `revoked`.

## Когда нужен человек

| Признак | Где видно | Действие |
|---|---|---|
| Ошибки задачи («нужен индекс») | журнал функции, `*-server-errors` | выпустить индексы (`firestore-rules-indexes-ttl-release.md`, шаг B) |
| Запись в `deadLetter` | чтение коллекции (только чтение) | в облаке не трогать до production-консоли; записать в журнал инцидентов; для синтетики — оставить |
| Неверное состояние брони у пользователя | жалоба, чтение документа | не править документ вручную; исправление — новым кодом и выкладкой, либо отменой брони пользователем |

**Ручная правка документов Firestore запрещена** (нет аудита, обходит владельца-сервиса). Исключение — только решением владельца с записью.
